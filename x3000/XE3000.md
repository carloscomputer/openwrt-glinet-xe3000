# GL-XE3000 (Puli AX) build of this tree

This tree is a 1:1 copy of vjt/openwrt-glinet-x3000 (tag `jeeves-r10`, which is already based on OpenWrt v25.12.6 plus newer branch commits),
with the differences below. The directory is still called `x3000/` on purpose,
so that vjt's updates stay a plain rebase.

1. `x3000/config.common` selects the `glinet_gl-xe3000` device profile.
2. `x3000/lib/feed.sh` names the XE3000 image files and points the release
   tooling at this fork's own apk feed and signing key.
3. `x3000/feeds.conf` pins the package feeds to the commits of OpenWrt
   v25.12.6 when the tree was rebased onto that release; otherwise it is
   vjt's file unchanged.

4. `x3000/config.public` selects extra packages for the public image
   (OpenVPN, WireGuard, Tailscale), see the marked block at its end.

The GL-X3000 and GL-XE3000 share one device tree include
(`mt7981a-glinet-gl-x3000-xe3000-common.dtsi`), which carries
`pcie_port_pm=off`, so the modem fix applies to both.

The 5G watchdog and its Prometheus collector come from `quectel-5g-tools`
unchanged: metrics are `quectel_watchdog_*` (alert on
`quectel_watchdog_probe_ok == 0`). After installing or upgrading the package,
run `/etc/init.d/prometheus-node-exporter-lua restart`, because the exporter
caches its collectors at start.
